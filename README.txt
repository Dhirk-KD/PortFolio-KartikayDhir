KARTIKAY DHIR - RESUME WEBSITE (plain HTML, ready for GitHub Pages)
===================================================================

PUT IT ON GITHUB PAGES
1. Create a new GitHub repository (public).
2. Upload everything in this folder to the repository (index.html must be at the top level).
3. Repo Settings > Pages > Deploy from a branch > main > / (root) > Save.
4. After a minute the site is live at https://YOUR-USERNAME.github.io/REPO-NAME/
   (Name the repo YOUR-USERNAME.github.io to get the shorter address.)
5. LinkedIn: Contact info > Website > paste the address.

CONTACT FORM (needed because GitHub cannot run PHP)
1. Make a free account at formspree.io and create a form using your email.
2. Copy the form id (the part after /f/).
3. In contact.html replace YOUR_FORM_ID with it.

THINGS TO EDIT
- images/kartikay.png : your photo
- resume/Kartikay-Dhir-Resume.pdf : replace with your final resume (keep the name)
- index.html : certificates (see "CERTIFICATIONS" comment)
- projects.html : add project cards
- experience.html : swap logo letters for real logo images
- The menu and footer are repeated in each page, so change them in all four files.

TEST ON YOUR PC: double-click index.html.
