Windows Server 2022 – Active Directory & Enterprise Security Lab

Designed and implemented a Windows Server 2022 enterprise lab environment simulating a real organizational network.

Configured Active Directory Domain Services (AD DS), DNS, and DHCP. Created Organizational Units (Finance, HR, IT), managed users and security groups, and implemented Group Policy Objects (GPOs) for password policies, account lockout, security restrictions, and department-based drive mapping using item-level targeting.

Configured NTFS permissions for secure departmental file shares and enabled advanced security auditing for sensitive Finance data (Event ID 4663).

Performed testing and troubleshooting by simulating DNS failures, unauthorized access attempts, and account lockouts. Validated configurations using gpupdate, gpresult, auditpol, and Event Viewer.

VetClinicDB – Veterinary Clinic Database (Microsoft SQL Server)

Designed and built a relational database in Microsoft SQL Server that manages the records of a veterinary clinic: owners and pets, veterinarians, appointments, treatments, medications, prescriptions and invoices. Completed as an individual project for INFT 3105 Database Management at Durham College.

Worked in three phases: a nine-table schema, normalization to 3NF that grew it to 11 tables, and transaction management. Business rules are enforced in the database with primary and foreign keys, CHECK and UNIQUE constraints, and a persisted computed invoice total.

Loaded 2,380 rows of synthetic data and wrote three T-SQL transactions (client registration, visit checkout and refund), each across five tables, using TRY...CATCH with rollback.

Verified the design with row-count and join queries, and by testing failures: an over-dispensed medication triggered a constraint error (547) that rolled back the whole checkout, and a repeat refund was rejected by a guard clause (error 50003).

Skills used

  • Microsoft SQL Server
  • T-SQL
  • Database Design
  • Normalization (3NF)
  • ER Diagrams
  • Transactions (ACID)
  • Data Integrity
  • SSMS
