Windows Server 2022 – Active Directory & Enterprise Security Lab

Designed and implemented a Windows Server 2022 enterprise lab environment simulating a real organizational network.

Configured Active Directory Domain Services (AD DS), DNS, and DHCP. Created Organizational Units (Finance, HR, IT), managed users and security groups, and implemented Group Policy Objects (GPOs) for password policies, account lockout, security restrictions, and department-based drive mapping using item-level targeting.

Configured NTFS permissions for secure departmental file shares and enabled advanced security auditing for sensitive Finance data (Event ID 4663).

Performed testing and troubleshooting by simulating DNS failures, unauthorized access attempts, and account lockouts. Validated configurations using gpupdate, gpresult, auditpol, and Event Viewer.
